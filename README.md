# atlasaiconsultingllc.com

The Atlas AI Consulting website. A static page: four files, no build step, no framework.

    index.html        the page
    site.js           the audit trail, the functional area board, and the Atlas map figure
    scrollcraft.js    scroll engine (vendored)
    scrollcraft.css   scroll engine stylesheet (vendored)

Published with GitHub Pages from the default branch. A push redeploys.

The board and the map are representative, and say so on their faces. Neither is ever to be
replaced with harvested client data.
